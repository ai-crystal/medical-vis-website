张磾

← 项目团队

网站开发与服务器运维

English CV中文简历

张磾参与 Crystal 网站的设计、全栈开发和服务器运维。他具有三年以上实验室数字化经验，主要从事 AI 智能体应用、数据自动化和业务流程数字化。

技能栈

AI 工作流与智能体

  • 智能体设计与开发。将业务目标拆分为可独立执行和验证的任务，定义各阶段的输入、输出与交接条件。在 Litnebula 中实现电子书解析、实体和关系提取、作者信息补全、去重与人工审核发布。
  • 提示词工程与结构化输出。使用提示词和 JSON Schema 约束模型输出，处理解析失败与重试。结合置信度判断和人工复核，将不确定结果分流，保留批次记录以便追踪。
  • 检索、语义匹配与工具接入。熟悉检索增强生成（RAG）和模型上下文协议（MCP）。在图谱工作流中结合字符匹配、向量语义相似度和模型复核，实现实体消歧与去重。
  • 工作流编排与质量控制。使用后台任务队列处理批量导入，管理并发、限流与取消。以自动化测试覆盖关键流程，以审核记录追踪结果从提取到发布的变化。

全栈工程与业务自动化

  • 编程与 Web 开发。使用 Python、SQL 和 Linux 开发数据工具与服务，使用 FastAPI 和 SQLite 构建 API 和数据层。具备 HTML/CSS、Vue 3、React、TypeScript 与 Three.js 开发经验，熟悉 Nginx 部署及服务器运维。
  • 数据处理与商业智能。使用 Python、SQL 和 Power Query 完成数据清洗、合并及标准化，使用 Power BI 构建质量分析、预警和运营看板。
  • 低代码与流程自动化。使用 Power Automate、Power Apps 和明道云 HAP 搭建业务应用，覆盖数据收集、审批、通知、报告和库存跟踪。能从需求梳理推进到交付与用户培训。
  • 英语与跨团队协作。能够用英文处理技术文档、进行书面沟通和工作汇报，并与业务和技术团队协作明确交付要求。

教育与经历

  • 山东理工大学，物理学本科。
  • 实验室数字化专员｜快消行业（2022–2025）。开发实验室数据处理和可视化工具，推动样品登记、报告生成和库存管理等流程自动化。

代表项目

  • Litnebula 文学影响图谱。独立开发全栈应用，从电子书中提取作者、作品及提及关系，经人工审核后发布为交互式 3D 图谱。
  • 实验室质量与预警。自动整理样品和原料质量数据，通过仪表盘集中展示分析结果与预警信息。
  • 实验室数据管理。搭建采购和库存管理流程，支持申请、审批与库存跟踪，并自动规范化学品名称。
